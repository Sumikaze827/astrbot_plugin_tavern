# AI 酒馆

> 📣 **项目交流群：QQ 群 `1094220887`**  
> 欢迎交流世界包制作、插件测试、问题反馈与版本更新；入群时请说明来自 AI 酒馆项目。

> 版本：`v0.12.0`  
> 作者：`Ghostberry`  
> 数据库：Schema 12  
> 世界包协议：v2—v5  
> AstrBot：`>=4.26,<5`

AI 酒馆是一款面向 AstrBot 群聊的纯文本多人跑团与互动叙事插件。它提供 AI DM 与人工
DM、角色创建、多人回合、行动选项、集体投票、机器检定、托管代操作、NPC、关系、背包、
经济、世界状态、Token 配额、存档回滚、通知补偿和管理控制台。

插件只处理明确的酒馆指令和剧情行动。普通群聊不会调用酒馆叙事模型，也不会写入副本时间线。

## 安装

1. 在 AstrBot 插件管理器上传 `astrbot_plugin_tavern-v0.12.0.zip`，或将完整源码目录
   `astrbot_plugin_tavern` 放入 AstrBot 插件目录。
2. 重启或重载插件，确认版本显示为 `v0.12.0`。
3. 在插件配置中至少填写一个真实的管理员用户 ID。
4. 选择主聊天模型；需要图片行动时再配置图片转述模型。
5. 建议启用群白名单，并只添加实际用于跑团的群。
6. 管理员在目标群发送 `/酒馆 开启` 完成首次绑定。

从旧版升级前，请备份整个插件数据目录。数据库会自动迁移至 Schema 12，并在迁移前创建
一致性备份。旧存档和世界包 v2—v5 保持兼容；运行中的副本继续使用创建时冻结的世界快照。

## 快速开始

管理员创建副本：

```text
/酒馆 开启 [世界标识]
```

玩家加入并完成角色卡：

```text
/酒馆 加入
/酒馆 角色
/酒馆 准备
```

管理员确认阵容并开演：

```text
/酒馆 阵容
/酒馆 开演
```

游戏中常用操作：

```text
jg A                     选择 A 选项
/酒馆 选择 A             完整写法，可在字母后附加简短演绎
/酒馆 投票 A             参与集体决策
/酒馆 状态               查看当前副本状态
/酒馆 暂离               暂时离开行动队列
/酒馆 返回队列           申请返回
/酒馆 安全暂停           立即冻结剧情和计时
```

管理员可使用 `/酒馆 帮助` 查看当前版本支持的完整指令和权限说明。

## 人工 DM

管理员或获授权的主持人可以接管叙事：

```text
/酒馆 主持 开启
/酒馆 主持 状态
/酒馆 主持 指引 <导演说明>
/酒馆 主持 推进
/酒馆 主持 直述 <公开剧情>
/酒馆 主持 交棒 <角色或 NPC>
/酒馆 主持 自动 <角色>
```

人工 DM 的可用操作由副本权限和世界包策略共同限制。WebUI 中按钮被禁用时会显示原因；
后端仍会再次校验权限，不能通过直接请求绕过。

## 控制器 WebUI

控制器提供以下主要页面：

- 副本实时仪表盘、回合顺序、选项与投票；
- 人工 DM、角色托管与代操作；
- 世界包、NPC、关系、背包和经济管理；
- 存档、回滚、剧情账本、场景时钟和审计日志；
- Token 用量、通知待办、扩展点与事件、系统设置与诊断。

WebUI 地址、登录方式和访问权限以 AstrBot 后台及插件日志为准。危险操作需要相应权限并会
留下审计记录。

## 平台兼容与消息投递

插件不再使用 QQ REST API，也不发送富卡片。所有消息统一通过 AstrBot 适配器的文本能力
处理，因此可在 AstrBot 支持的群聊平台上尝试运行。

群内即时回复与主动私聊、定时通知属于不同能力。某个平台能正常回复指令，不代表一定支持
主动消息。主动发送失败时，插件会记录真实原因，并按世界包策略执行：

- `next_event`：进入待发送队列，在目标下一次事件到达时补发；
- `webui_only`：只保留在 WebUI 待办中；
- `discard`：记录失败但不排队。

待发送通知可在 WebUI 中查看、重试或忽略。插件不会将失败发送误报为成功。

## 世界包

世界包可以定义世界规则、角色卡、属性生成、骰制、NPC、资源、经济、能力、状态效果、
互动规则和多人体验策略。`chat_experience` 可选接口用于配置建卡通道、聚光灯、集体决策、
缺席玩家、安全工具、剧情回顾、检查点、未决线索、NPC 意图、消息回退和人工 DM 权限。

新增字段均为可选。旧世界包导入后会规范化为运行时合同，未知扩展字段在编辑、保存和导出时
继续保留。不要直接替换进行中副本的世界规则；需要新规则时应新建或克隆副本。

模板位于 `templates/`，详细说明见：

- [世界包接口](docs/WORLD_PACKAGE.md)
- [世界创作指南](docs/WORLD_AUTHORING.md)
- [世界包 v5 协议](docs/WORLD_SCHEMA_V5.md)

## 数据与安全

- 关键写操作使用事务和幂等标识，检定结果先持久化再交给模型续写。
- 存档、回滚和读档保留剧情、行动者、选项、投票与计时状态。
- 读档或回滚后副本保持暂停，需要重新准备并继续。
- 数据库迁移、备份导入、世界包导入和危险 WebUI 操作会执行校验并记录审计。
- 请定期导出完整备份；自动迁移备份不能替代整目录备份。

## 常见问题

### 指令没有响应

检查管理员 ID、群白名单、指令前缀、目标平台实例和 AstrBot 日志。可依次尝试 `/酒馆`、
`／酒馆`、`!酒馆` 或 `！酒馆`。

### 主动消息没有送达

前往 WebUI 的通知待办查看适配器错误和回退状态。确认平台是否支持主动发送，再决定重试、
等待下一次事件补发或忽略。

### 扩展点与事件页面读取失败

页面会保留已经成功读取的数据，并显示具体失败模块。点击“重新读取”重试；若仍失败，请在
审计和 AstrBot 日志中查找扩展注册表或事件订阅异常。单个异常扩展不会阻断其他项目展示。

### 旧世界更新后副本没有变化

这是冻结快照的预期行为。基于新版世界新建或克隆副本，避免运行中规则漂移。
